IV spread alpha-decay workflow

A visual summary of the analysis pipeline used to test whether the paper-style option-implied volatility spread still predicts index returns. This page describes the methodology only and intentionally omits results.

End-to-end pipeline

1

Load option chain

Read daily option rows with spot, strike, maturity, bid, ask, mid, implied vol, dividend, and risk-free rate.

2

Filter quotes

Keep usable index options: 10-60 days to expiry, IV between 3% and 200%, and option mid-price at least $0.125.

3

Build signals

Construct paper-style OTM put minus ATM call spread, bid-ask-weighted spread, delta-bucket spread, and ATM call-minus-put alternatives.

4

Align returns

Compute forward index log returns and subtract the risk-free rate to form excess returns at each horizon.

5

Test prediction

Estimate predictive regressions using non-overlapping multi-day windows to avoid stale overlapping-horizon inference.

6

Assess trading use

Run expanding-window timing rules, threshold variants, and ATM call-put gating, then compare gross and net execution behavior.

Core spread definition

The primary signal follows the paper's put-minus-call construction, not a simple ATM call-minus-put skew measure.

\[ VS_t=\overline{\sigma}^{p}_{t,OTM}-\overline{\sigma}^{c}_{t,ATM} \] \[ OTM\ put: 0.80\le K/S\le0.95,\quad ATM\ call:0.95\le K/S\le1.05 \]

Return target

The analysis tests whether today's spread forecasts future index excess returns rather than raw returns.

\[ R^e_{t+h}=\log(S_{t+h}/S_t)-\sum_{j=1}^{h} r^f_{t+j}/252 \] \[ R^e_{t+h}=\alpha+\beta VS_t+\varepsilon_{t+h} \]

Signal variants

Paper-style equal weight

Average all eligible OTM put IVs and subtract the average eligible ATM call IVs.

Quote-quality weighted

Weight each option by inverse percentage bid-ask spread.

\[w_i=\left((Ask_i-Bid_i)/Mid_i\right)^{-1}\]

Delta-bucket robustness

Estimate Black-Scholes deltas and compare 10-40 delta puts against 45-55 delta calls.

ATM call-put signal

Test the more traditional \(IV^c_{ATM}-IV^p_{ATM}\) signal separately as a possible bullish gate.

Threshold timing

Move to cash only when the forecast is sufficiently negative, rather than using the sign alone.

Gated timing

Allow a positive ATM call-put signal to keep the strategy invested when the paper-style forecast is bearish.

Inference choices

Daily horizon
OLS with heteroskedasticity/autocorrelation-aware standard errors.
Daily returns are noisy and can have serial dependence.
Short-horizon signals can look unstable across regimes.
Multi-day horizons
Use non-overlapping forward returns for 5d, 10d, and 21d tests.
Avoids inflated significance from overlapping return windows.
Fewer observations means lower statistical power.
Risk-free rate
Subtract dataset risk-free rate for excess returns; cash earns risk-free in timing tests.
Makes the comparison fairer than raw return timing.
Assumes the dataset rate is correctly aligned and annualized.
Costs
Subtract 1bp when the strategy switches between index and cash.
Separates gross forecast value from basic execution drag.
Does not fully model slippage, taxes, financing, or capacity.

Backtest workflow

Training data
At each decision date, fit the predictive equation using only observations available before that date.
Forecast
Compute the next-day expected excess return from the current IV-spread signal.
Allocation
Invest in the index when forecast excess return is above the selected cash threshold; otherwise hold cash at the risk-free rate.
Net return
Apply the realized index or cash return, then subtract the switching cost when allocation changes.
\[ I_t=\mathbf{1}\{\widehat{R}^{e}_{t+1}>-\theta\},\quad r^{strategy}_t=I_t r^{index}_t+(1-I_t)r^f_t-cost_t \]

Known limits

  • The raw file has no option volume or open interest, so the original volume/open-interest spread variants cannot be exactly replicated.
  • Bid-ask weighting is a quote-quality proxy, not a direct proxy for volume, open interest, or signed option demand.
  • Threshold and gate variants are exploratory unless they are locked before a future out-of-sample test.
  • The workflow tests index timing, not a self-financing option portfolio.
